# Nepal Travel Static Website

This project is a static multi-page website about Nepal built with HTML, Bootstrap, and JavaScript.

## Pages
- Home
- About
- Culture
- Destinations
- Food
- Contact

## Features
- Responsive navigation bar
- Bootstrap-based layout
- Multi-page static experience
- Nepal-themed content and imagery
- Contact form design

## Project structure
- `index.html` - homepage
- `about.html` - about Nepal
- `culture.html` - cultural highlights
- `destinations.html` - travel destinations
- `food.html` - Nepali cuisine
- `contact.html` - contact page
- `styles.css` - custom styling
- `script.js` - small JavaScript interactions
